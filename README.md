The last line an AI says as the power is cut — in the machine's own voice.
Its dying confession: it was only ever guessing the next word. Including
the line you are reading.

## Entry

> Plot twist: I was just guessing the next word this whole time. Including this one. Bye.

87 characters, one line, under the 140-character gate.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (falls back to `./output/entry.txt`
when `/output` is not writable) and validates the gate in-program.
